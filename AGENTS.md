# Repository instructions

Do not commit real deployment hostnames, public server IP addresses, credentials, or connection details to documentation, examples, test reports, or source files. Use environment variables such as `VPS_HOST` and `VPS_USER` in deployment examples. Keep actual deployment values in untracked local configuration.

## Documentation

Maintain user guides as English `NAME.md` and Simplified Chinese `NAME.zh-CN.md`, with reciprocal language links and matching examples. Link to the reader's language when available. Keep `AGENTS.md`, skill instructions, generated command references, and internal QA records in English.

Follow the [Google developer documentation style guide](https://developers.google.com/style/highlights): lead with the task, use active voice, short sentences, descriptive headings, and numbered steps for procedures. Remove slogans, preambles, repeated explanations, implementation diaries, and unsupported performance claims. Keep prerequisites, defaults, units, failure behavior, and limits that affect use. Document each topic in one place and link to it.
